# On-a-complete-written-proof-of-the-Riemann-Hypothesis
In this paper, we show that every nontrivial zero of ζ(s) has real part 1/2. The proof
follows Sernau’s shorter arrangement of the Alpöge construction. We provide a complete
written account of the proof, relying solely on results from the existing mathematical literature, without reference to any part of the Lean formalization.

This proof is based on the readable version of the short lean proof (https://github.com/lsernau/grh-lean).
